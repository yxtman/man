# 曼联球迷指南(Man United Fans Guide)

曼联中文球迷自制指南网站,深色红金史诗风格。纯静态多页站,无构建步骤,由 GitHub Pages 托管。

**在线地址**:https://yxtman.github.io/man/

## 页面

| 页面 | 内容 |
|---|---|
| `index.html` | 首页:俱乐部概览与大事时间线 |
| `history.html` | 历史与荣耀:20 冠荣誉墙、慕尼黑空难纪念、1999 三冠王专题、历任主帅谱系 |
| `legends.html` | 传奇与时刻:贝斯特/查尔顿/劳/坎通纳/贝克汉姆/吉格斯/斯科尔斯/C罗/鲁尼,经典时刻 |
| `theater.html` | 老特拉福德:球场档案、四大看台、容量演变、百年故事 |
| `culture.html` | 球迷文化:红魔与徽章、球衣演变、队歌、德比文化、入门指南 |
| `team.html` | 球队现状:赛季回顾、主教练、夏窗动态、当前阵容(数据截至 2026 年 8 月,以官方为准) |
| `records.html` | 数据档案:队史射手榜、出场榜、俱乐部纪录 |
| `classics.html` | 名局与青训:名局档案、92 班、曼联女足 |
| `watch.html` | 观赛指南:时差、直播平台、老特拉福德观赛 |
| `404.html` | 404 错误页(noindex) |

## 技术说明

- 无框架、无构建步骤;系统字体栈;所有图形为几何 SVG / CSS
- 分享标签:9 页均含 Open Graph(`og:image` 指向自绘封面)与 canonical 链接
- SEO:`robots.txt` + `sitemap.xml`
- 站点风格参考 impeccable 设计体系(深色红金、斜切角、几何菱形)
